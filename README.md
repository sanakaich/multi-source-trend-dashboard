# 📊 Multi-Source Trend Analysis Dashboard

A professional end-to-end data pipeline that ingests trending data from **Reddit** and **YouTube**, detects anomalies, and visualizes insights in a clean **Streamlit dashboard**.

---

## 🚀 Features

- 🔄 Automated ETL pipeline (Reddit + YouTube API)
- 📈 Rolling Z-score anomaly detection
- 📊 Interactive Streamlit dashboard
- 🎯 Filters by source, category, time, keywords
- 📤 CSV export of filtered data
- 🧱 Production-ready project structure

---

## 🛠 Tech Stack

- Python
- Pandas, NumPy
- PRAW (Reddit API)
- YouTube Data API v3
- Streamlit
- Altair
- dotenv
